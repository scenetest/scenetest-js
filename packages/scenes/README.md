# @scenetest/scenes

CLI runner for [Scenetest](https://github.com/scenetest/scenetest-js) scene specs. Discovers and executes scene files using Playwright.

```bash
npm install -D @scenetest/scenes
```

```bash
npx scenetest run
```

See the [monorepo](https://github.com/scenetest/scenetest-js) for full documentation.
